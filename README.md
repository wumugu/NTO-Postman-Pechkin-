# Контест почтальона Печкина

Задача I из контеста: сколько задач успеет решить Печкин за `k` минут, если задачу номер `i` он решает ровно за `i` минут, а всего задач `n`.

## Условие

- Ограничение времени: 1 секунда
- Ограничение памяти: 256 МБ
- Ввод: стандартный ввод или `input.txt`
- Вывод: стандартный вывод или `output.txt`

**Ввод.** Два целых числа `n` и `k` через пробел: 1 ≤ n ≤ 3·10^9, 1 ≤ k ≤ 5·10^18.

**Вывод.** Одно число: количество задач, которые Печкин успеет полностью решить за `k` минут. Задача, сданная в последнюю минуту контеста, засчитывается.

### Примеры

| Ввод   | Вывод |
|--------|-------|
| `5 10` | `4`   |
| `5 9`  | `3`   |
| `5 100`| `5`   |

## Идея решения

Задачи решаются по порядку, поэтому на первые `m` задач уйдёт `1 + 2 + ... + m = m(m + 1) / 2` минут. Нужно найти наибольшее `m`, для которого это число не превышает `k`.

Решаем неравенство `m(m + 1) / 2 ≤ k`:

```
m ≤ (sqrt(8k + 1) - 1) / 2
```

Чтобы не терять точность на больших числах (k до 5·10^18), используется целочисленный корень `math.isqrt`. Ответ: `min(n, m)`, так как задач всего `n`.

Сложность: O(1).

python3 solution_I.py < input.txt
